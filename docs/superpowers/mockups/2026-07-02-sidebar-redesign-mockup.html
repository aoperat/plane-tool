공통 변경 사항 (세 안 모두 포함)
· 헤더 이모지(📌⟳⚙) → 일관된 SVG 아이콘 + 28×28px 히트 영역, 호버 배경 표시
· 상태 변경 버튼 확대 (14px 아이콘 → 26~28px 버튼)
· 시작일을 사이드바에서 표시 + 수정 가능 ("7/1 → 7/4" 형식, 마감일만 있으면 "~ 7/8")
· 날짜 클릭 시 QuickAdd와 동일한 날짜 프리셋 팝오버(오늘/내일/다음 주 + 달력) 재사용
· 값이 비어 있는 필드도 진입점 노출 (A안: 점선 칩, B안: 회색 버튼, C안: "설정 안 됨")

A안 · 칩편집 가능성이 항상 보임 + QuickAdd와 UI 문법 통일. 행 높이 중간(~58px). 추천.
B안 · 인라인밀도 최고(행 ~52px), 지금과 가장 비슷해 이질감 없음. 단, 호버 전에는 우선순위·날짜가 버튼인지 안 보임 — "구분 어렵다"는 문제를 절반만 해결.
C안 · 카드가장 명확(라벨까지 표시)하지만 행이 커서 320px 폭·다작업 환경에서 스크롤 부담. 작업 수가 적은 사용자에게 적합.

프로젝트 헤더 개선 (A안 최종 패널)
· 헤더 행 전체가 호버 배경이 있는 버튼 — 접기/펼치기 가능함이 즉시 보임 (접힌 그룹은 ▾가 회전)
· 프로젝트 식별자 배지(WEB, MOB…) 표시 — 색 점만보다 구분이 빠름 (Plane API의 identifier 필드, 이미 받아오고 있음)
· 카운트 → 완료 진행률 링 + "완료/전체" (예: 1/2) — 오늘 얼마나 쳐냈는지 한눈에
· 헤더 호버 시 + 버튼 → 해당 프로젝트가 미리 선택된 QuickAdd 열기 (선택 사항)
