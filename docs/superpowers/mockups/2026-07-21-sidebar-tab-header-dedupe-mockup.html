사이드바 — 탭과 섹션 헤더의 중복 정리

탭을 켜면 같은 정보가 두 줄에 걸쳐 반복된다: 탭은 담당 작업 5, 바로 아래 섹션 헤더는 나에게 할당된 작업 5 — 같은 목록을 다른 이름으로 두 번 부르고, 개수도 두 번 보여준다. 게다가 "내가 할당한 작업" 탭에서는 탭 개수(전체)와 섹션 개수(오늘만 필터 적용)가 서로 달라질 수 있어 어느 쪽이 맞는지 헷갈린다.

다크 모드

라이트 모드

탭이 꺼져 있을 때 (설정에서 "할당한 작업 보기" off) — 회귀 확인

탭 바가 없으면 섹션 헤더가 유일한 라벨이므로 제목과 개수가 반드시 남아야 한다. 각 안이 이 상태에서 어떻게 보이는지.

구현 메모 — A안: renderActiveTabView()에서 탭 표시 여부에 따라 sectionTitle/taskCount만 숨기고 .h에 tools-only 클래스를 토글한다. 마크업 변경 없음, 가장 작은 diff. B안: 토글 두 개(showAllDelegated, hideDone)를 .sb-tabs 안으로 옮기고 아이콘만 남긴다 (라벨은 title 툴팁으로). 세로 한 줄을 통째로 회수해 목록이 그만큼 더 보인다. 탭이 꺼지면 이 줄이 통째로 사라지므로 .sb-tabs는 항상 렌더하고 탭 버튼만 숨기는 처리가 필요하다. C안: 탭에서 .count만 제거 — 개수는 섹션 헤더가 전담. 변경은 가장 쉽지만 탭만 봐서는 반대편 탭에 몇 건이 있는지 알 수 없다.

덤으로 고칠 것 — 어느 안을 택하든 "내가 할당한 작업"의 개수 기준을 한쪽으로 통일해야 한다. 현재 탭 카운트는 lastSidebarData.delegated.length(전체)인데 섹션 카운트는 오늘만 필터가 적용된 값이라 숫자가 어긋난다. 화면에 실제로 보이는 개수(필터 적용 후)로 맞추는 쪽을 권한다.
