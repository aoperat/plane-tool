1Windows 토스트 — 백그라운드 동기화가 새 할당을 감지하면 즉시 표시. 누가·무엇·마감·우선순위를 담고, 확인을 누르면 그 자리에서 인지 처리됩니다.
2트레이 뱃지 — 미확인 할당 수. 토스트를 놓쳐도 뱃지는 확인 전까지 사라지지 않습니다. 미확인 상태가 지속되면 일정 주기(기본 2시간, 설정 가능)로 토스트를 다시 띄웁니다.
