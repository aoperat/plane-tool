# 할당 인지 시스템 & 맡긴 작업 창 — 설계 스펙

- 날짜: 2026-07-03
- 상태: 사용자 승인 대기
- 목업: `docs/superpowers/mockups/2026-07-03-assignment-awareness-mockup.html`

## 목적

다른 사람에게 작업을 할당했을 때 **받는 사람이 반드시 인지**하게 만들고,
**맡긴 사람은 확인 여부와 진행 상황을 추적**할 수 있게 한다. 두 기능은 하나의
루프다: 할당 → 감지 → 알림(확인까지 반복) → 확인 기록 → 할당자 추적 창에 반영.

## 핵심 설계 결정

1. **인지의 종료 조건은 명시적 확인**이다. 토스트 1회로 끝내지 않고, 사용자가
   "확인" 버튼을 누를 때까지 트레이 뱃지·사이드바 수신함·주기적 재알림이
   유지된다.
2. **확인 기록은 Plane 자동 댓글**로 남긴다. 별도 서버 없이 Plane이 진실의
   원천이 되고, 할당자 쪽 앱이 이 댓글을 읽어 ✓ 확인함 / ● 미확인을 판정한다.
   앱을 안 쓰는 팀원도 Plane 웹에서 같은 기록을 본다.
3. **제약**: 받는 쪽 알림은 상대도 Quick Dock을 실행 중일 때만 동작한다
   (Plane은 데스크톱 푸시가 없음). Plane 자체 이메일/웹 알림이 보완재.

## Part A — 할당 인지 (받는 사람)

### 감지

- 백엔드(tokio 백그라운드 태스크, 기존 업데이트 체크 태스크와 같은 패턴)가
  **60초 간격**으로 "나에게 할당된 미완료 작업" 목록을 조회하고, 로컬에 저장된
  **본 적 있는 이슈 ID 집합(seen-set)** 과 diff해 새 할당을 찾는다.
- seen-set은 설정과 같은 방식으로 로컬 파일에 영속화한다(`config.rs` 패턴).
  최초 실행 시(파일 없음)는 현재 할당 전체를 seen 처리해 과거 작업이 한꺼번에
  알림으로 쏟아지는 것을 막는다.
- 할당자 식별: 새 이슈의 Activity API에서 assignee를 설정한 actor를 찾는다.
  실패 시 created_by로 폴백, 그것도 없으면 "누군가"로 표시.
- 내가 나에게 할당한 작업(QuickAdd 기본 동작)은 알림 대상에서 제외한다.

### 알림 3중 장치

1. **Windows 토스트** (`tauri-plugin-notification`): "김PM님이 '…'을
   할당했습니다 · 마감 7/5 · 긴급". 클릭 시 사이드바를 연다.
2. **트레이 뱃지**: 미확인 건이 있으면 트레이 아이콘을 점 찍힌 변형으로
   교체하고 툴팁에 "미확인 할당 N건" 표시. 0건이 되면 원래 아이콘 복귀.
3. **사이드바 수신함**: "나에게 할당된 작업" 위에 별도 강조 섹션
   "새로 할당됨 (N)". 각 항목에 할당자·경과 시간·우선순위·마감 표시,
   "✓ 확인했습니다" / "열기" 버튼.
4. **재알림**: 미확인 건이 남아 있으면 주기(기본 2시간, 설정)마다 토스트를
   다시 띄운다. 재알림은 묶어서 1개("미확인 할당 2건")로 보낸다.

### 확인 처리

- "✓ 확인했습니다" 클릭 → Comments API로 해당 이슈에 마커 댓글
  `🔔 할당을 확인했습니다 (Quick Dock)` 작성 → 성공 시 수신함에서 제거하고
  일반 목록으로 합류, 뱃지 갱신. 댓글 작성 실패 시 수신함에 남기고 에러 표시.
- 토스트의 "확인" 액션 버튼도 같은 경로를 탄다.
- 마커 문자열은 상수로 공유해(작성·판정 양쪽) 오타로 어긋나지 않게 한다.

## Part B — 맡긴 작업 창 (맡긴 사람)

### 창

- 새 윈도우 `delegated` — `src/delegated/` + 기존 `src/shared/` 패턴.
  사이드바와 같은 도크 스타일(우측 고정, 360px), 전역 단축키로 토글
  (설정 필드 `delegated_shortcut`, 기본값 미지정 = 비활성).
- 사이드바 더보기(⋯) 메뉴에도 "맡긴 작업" 항목 추가(단축키 없이도 진입 가능).

### 데이터 (MVP 범위)

- **내가 생성했고(created_by = me) 담당자에 내가 없는** 미완료+오늘 완료 작업.
  남이 만든 이슈를 내가 재할당한 경우는 v2(Activity 스캔 필요)로 미룬다.
- 백엔드 커맨드 `fetch_delegated_data`: 프로젝트별 이슈 조회(기존
  `fetch_sidebar_data`의 N+1 패턴 재사용) 후 위 조건으로 필터.
- **확인 여부 판정**: 미확인으로 기억 중인 항목만 Comments API를 조회해
  담당자가 작성한 마커 댓글을 찾는다. 찾으면 ✓ 확인함으로 캐시(로컬 영속)하고
  이후 재조회하지 않는다 — 레이트 리밋 보호.
- 담당자가 여러 명이면: 표시는 첫 담당자 그룹, 확인은 누구든 1명이 마커를
  남기면 ✓로 판정한다 (MVP 단순화).
- 갱신 시점: 창 포커스 시 + 새로고침 버튼, 사이드바와 동일한 3초 쿨다운 패턴.

### 화면 구성

- 요약 칩: **미확인 N · 지연 N · 정체 N** (칩 클릭 = 해당 항목만 필터 토글).
  - 지연: `target_date < 오늘` && 미완료.
  - 정체: 마지막 갱신(`updated_at`) 후 3일 경과 && 미완료 (기준일 상수, 추후 설정화).
- 담당자별 그룹핑(아바타 + 이름 + 건수), 그룹 접기는 사이드바 패턴 재사용.
- 행: 상태 아이콘 · 이름 · 확인 뱃지(✓ 확인함 / ● 미확인 + 경과) · 마감/지연/정체 칩.
- 행 호버 액션: **리마인드**(담당자 멘션 댓글 — 확인 요청 문구 자동 작성),
  **마감 조정**(기존 날짜 팝오버 재사용). 행 클릭 = 기존 수정 모달.
- 완료된 항목은 사이드바와 같은 취소선+흐림 처리, "오늘 완료"만 표시.

## 설정 추가

`Settings`(`src-tauri/src/config.rs`) + 설정 화면:

| 필드 | 타입 | 기본값 | UI |
|---|---|---|---|
| `assign_notify_enabled` | bool | `true` | 체크박스 "작업 할당 알림" |
| `assign_remind_hours` | u32 | `2` | 숫자 입력(시간), 최소 1 — 미확인 재알림 주기 |
| `delegated_shortcut` | String | `""` (비활성) | 단축키 입력(기존 단축키 필드 패턴) |

모두 `#[serde(default = ...)]`로 기존 설정 파일과 호환.

## 엣지 케이스

- **상대가 앱 미사용**: 영원히 ● 미확인으로 남는다 — 이는 버그가 아니라
  정보("아직 인지 확인 안 됨")다. 리마인드 댓글은 Plane 웹/이메일 알림을 태운다.
- **오프라인/서버 불가**: 폴링 실패는 조용히 다음 tick으로. 확인 버튼 실패만
  사용자에게 표시.
- **중복 마커 댓글**: 확인 처리 전 수신함에서 이미 제거된 항목은 버튼이 없으므로
  중복 작성 경로 없음. 재설치로 seen-set이 초기화돼도 최초 실행 seen 처리
  규칙이 재알림 폭주를 막는다.
- **레이트 리밋**: 폴링 60초 간격 고정, 댓글 조회는 미확인 항목으로 한정 +
  확인 판정 캐시. 기존 쿨다운 패턴 준수.
- **삭제/완료된 미확인 항목**: 폴링 결과에 없으면 수신함·뱃지에서 자동 제거.

## 테스트

기존 컨벤션대로 순수 로직을 분리해 단위 테스트 (vitest / cargo test):

- **diff 감지**(Rust): seen-set 대비 신규 판정, 최초 실행 전체 seen 처리,
  self-assign 제외, 사라진 항목 정리.
- **재알림 판정**(Rust): 미확인 존재 + 주기 경과 → 발송, 확인 후 → 미발송.
- **마커 댓글 판정**(TS 또는 Rust): 마커 포함 + actor가 담당자 → 확인,
  다른 사용자의 마커 → 미확인 유지.
- **분류 로직**(TS, `src/delegated/logic.ts`): 지연/정체 판정(경계일 포함),
  담당자별 그룹핑, 요약 집계, 필터 토글.
