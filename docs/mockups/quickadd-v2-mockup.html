1 · 현재(v1)와 나란히

v1은 담당자·시작일·마감일·상태·우선순위가 전부 칩 하나로 접혀 있고, 값을 바꾸려면 칩을 눌러 드롭다운을 열어야 합니다. 게다가 팝오버가 하나뿐이라 한 번에 한 항목만 펼칠 수 있습니다. v2는 다섯 항목을 라벨 붙은 다섯 줄로 펼쳐, 현재 값 확인도 변경도 클릭 한 번에 끝납니다.

3 · 프로젝트 검색 드롭다운

프로젝트 목록은 지금 그냥 나열됩니다 — 프로젝트가 늘면 스크롤해서 눈으로 찾아야 합니다. 검색창을 목록 맨 위에 붙여, 열자마자 커서가 거기 놓이고 타자를 치면 좁혀지게 합니다. 이 자리는 v1·v2가 공유하므로 두 버전에 함께 적용됩니다.

열자마자 — 커서는 검색창, 현재 선택에 ✓

검색어가 없으면 전체 목록입니다. 지금 하던 대로 그냥 눌러 고르는 흐름은 그대로고, 검색은 원할 때만 쓰는 추가 경로입니다.

"자" 입력 — 이름 중간에 걸려도 남는다

앞글자만이 아니라 이름 어디에 있든 걸립니다(디자인 시스템, QA 자동화). 영문은 대소문자를 가리지 않습니다. 결과가 없으면 "일치하는 프로젝트가 없습니다"가 뜹니다.

키보드 — ↑↓ 이동, ↵ 선택, Esc 닫기. 커서는 검색창에 머물러 있어서 좁히다가 바로 ↵로 고를 수 있습니다.

담당자·상태·우선순위·날짜를 접지 않고 한 화면에 보여줍니다. 창이 660px로 넓어집니다.

설계 메모

왜 설정으로 가르나 — v2는 창이 660px로 넓고 세로도 깁니다. 작은 노트북이나 제목만 빠르게 던져 넣는 사용 패턴에는 v1이 여전히 낫습니다. 한쪽으로 갈아엎지 않고 고를 수 있게 둡니다.

공유되는 것 — 두 버전은 같은 상태(선택한 프로젝트, 담당자, 날짜, 우선순위, 상태, 설명)를 다루고 제출 경로도 하나입니다. 다른 것은 그 상태를 그리는 방식뿐입니다.

키보드 계약 — Ctrl+Enter 제출, Esc 닫기, PgUp/Dn 시작일 ±1일, Ctrl+PgUp/Dn 마감일 ±1일은 v1과 동일하게 유지합니다. v1의 ←→ 칩 이동은 v2에서 행 안의 세그먼트 이동으로, Tab은 행 사이 이동으로 바뀝니다.

아직 안 정한 것 — 담당자 인라인 정렬 순서(가나다 vs 최근 지정순), 상태·우선순위에 숫자 단축키(Alt+1..5)를 줄지 여부, 프로젝트 검색에 초성 검색(ㄷㅈㅇ → 디자인 시스템)과 영타 오타 보정(ejwkdls → 디자인)까지 넣을지 여부.
