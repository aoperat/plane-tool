저장된 상태에선 입력창 대신 ✓ + 마스크(••••) + "저장됨" + [변경] 카드를 보여줌. "이미 토큰이 있다"가 한눈에 읽히고, 빈 입력창으로 인한 혼란이 원천 차단됨. [변경]을 누르면 아래 미입력 상태처럼 입력창으로 전환(포커스 이동), 새 토큰 저장 시 다시 카드로.

입력창 오른쪽 안에 초록 체크 + 테두리 초록 틴트. 레이아웃 변화 최소. 다만 체크가 "입력값이 유효함"으로 오독될 수 있고(폼 검증 관례), 저장 여부 텍스트가 없어 placeholder에 계속 의존함.
