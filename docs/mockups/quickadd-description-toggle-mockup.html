설명 입력란이 사라져 팝업이 한 줄 더 낮아짐. 토글 칩은 맨 오른쪽에 분리 배치(margin-left:auto)라 필드 값 칩들과 구분됨. 아이콘+"설명" 라벨, 평소엔 muted 톤.

토글 on → 칩이 액센트 색 + 옅은 배경으로 활성 표시, 설명 입력란이 제목 아래(기존 위치)에 나타나고 포커스 이동. 다시 누르면 숨김. 팝업이 닫혔다 열리면 항상 off로 초기화.

③ 수정모달 — 설명 없는 아이템 (토글 off)
할 일 수정
대시보드 차트 로딩 스피너 추가

QuickAdd와 동일한 토글 칩을 칩 로우 맨 오른쪽에 배치. 설명이 비어 있는 아이템은 off로 시작. 모달 폭을 540px로 통일(기존 480px)하고 칩 로우는 nowrap — 내용이 길면 칩 라벨이 말줄임(…) 처리되어 어떤 환경에서도 한 줄 유지.

④ 수정모달 — 설명 있는 아이템은 자동 on
할 일 수정
소셜 로그인 버튼 정렬 깨짐 수정
재현: iOS Safari에서 가로 모드 전환 시 버튼이 겹침.

이미 설명이 있는 아이템을 열면 토글이 자동으로 on — 기존 내용이 안 보이면 지워진 걸로 오해할 수 있으므로. 이 상태에서 토글을 끄면 입력란만 숨기고 내용은 유지(저장 시 그대로 보존).
